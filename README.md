# Chilangc

## What is this?
Once again I find myself starting a project I have no prospect of ever finishing.

Jokes aside, I wanted to get deeper in Rust, and I also want to learn more about compiler development, so I have decided that I will task myself with creating a compiler from scratch using Rust

I already have some language specifications ready, but I want to flesh them out more before publishing. What I have currently is a general sense of the syntax and lexical tokens of the language.

## Do you believe this will be useful for anyone?
If I say with complete honesty, no, this project is mostly for my own satisfaction and learning.

Despite that, I do plan on making a language decent enough that you can play around and have fun with, even if not a great tool in the toolbox

I also plan to compile it to llvm IR, so I do believe it will be nice for multi architecture development!
